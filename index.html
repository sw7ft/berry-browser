Modern web on hardware that refused to die.

Berry Browser is a windowed Chromium app for BB10 phones — GPU rendering, TLS 1.3, YouTube, WhatsApp Web, and a UI built for square Passports and classic keyboards. This site is the home for releases and experiments, not the multi‑gigabyte engine tree.

What this is

BlackBerry 10 shipped with an aging WebKit fork. Years of work on Chromium for BB10 turned a headless content_shell experiment into a real browser: EGL + Skia, a Skia-drawn toolbar, bundled root CAs, network-layer blocking, and packaging as an installable .bar.

Berry Browser is that app — the user-facing side of the port. The engine, patches, and build history live in the chromium-for-bb10 repository (branch berry-v3). This repository is the launch pad: downloads, release notes, and experimental BAR files for testers.

Berry Browser also fits alongside BerryCore and berrycore.sw7ft.com for a modernized BB10/QNX userland — same ecosystem, different repo roles.

Quick install (sideload)
  1. Enable Development Mode (Settings → Security and Privacy).
  2. Sideload the .bar with Sachesi, DDPB, or an on-device manager that supports BAR installs.
  3. Launch Berry Browser from the home screen.

Some BerryCore workflows expect a rooted device and qpkg; sideload paths vary by setup — see BerryCore docs if you install via package manager instead.
